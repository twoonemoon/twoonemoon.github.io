# twoonemoon.github.io

Личное портфолио Семёна Гридина: Java/backend, embedded, audio.

Статический сайт без сборки и внешних зависимостей. `index.html`, `style.css`, `script.js`, локальные SVG в `assets/`.

## Локальный просмотр

```sh
python -m http.server 8000
```

Открыть `http://localhost:8000`. Языки RU/EN и светлая/тёмная тема переключаются в шапке; предпочтения сохраняются локально. При отключённом JavaScript доступна русская версия со всеми материалами и ссылками.

## Публикация

GitHub Pages: ветка `main`, каталог `/` (сохранить существующие настройки репозитория). Для обновления достаточно коммита и push. Сайт не собирает данные и не использует стороннюю аналитику.

Проекты описаны по открытым исходникам. Опыт и образование перенесены из предыдущей версии сайта. Обложки проектов — SVG-иллюстрации в общем стиле.

Анимированный ник основан на каллиграфии Great Vibes. Шрифт преобразован в векторные контуры с учётом лигатур и кернинга; три слоя периодических кривых Безье сходятся к надписи. Цикл — 48 секунд. SVG работает без JavaScript; при `prefers-reduced-motion` видна готовая надпись.

Генератор и лицензия шрифта — `scripts/name.py` и `scripts/fonts/OFL.txt` в репозитории [профиля](https://github.com/twoonemoon/twoonemoon). Для воспроизведения: `pip install -r scripts/requirements.txt`, затем `python scripts/name.py`.
