# twoonemoon.github.io

Личное портфолио Семёна Гридина: embedded-разработка, микроконтроллеры и свои проекты на C/C++.

Статический сайт без сборки и внешних зависимостей. `index.html`, `style.css`, `script.js`, локальные SVG в `assets/`.

## Локальный просмотр

```sh
python -m http.server 8000
```

Открыть `http://localhost:8000`. Языки RU/EN и светлая/тёмная тема переключаются в шапке; предпочтения сохраняются локально. При отключённом JavaScript доступна русская версия со всеми материалами и ссылками.

## Публикация

GitHub Pages: ветка `main`, каталог `/` (сохранить существующие настройки репозитория). Для обновления достаточно коммита и push. Сайт не собирает данные и не использует стороннюю аналитику.

Проекты описаны по открытым исходникам. Опыт и образование перенесены из предыдущей версии сайта. В проектах показан реальный скриншот TwoonemoonSoundLab из его публичного репозитория; декоративные обложки не используются.

Никнейм — нарисованная вручную SVG-подпись. Последовательные штрихи и короткое подчёркивание занимают 1,74 секунды, затем подпись остаётся видимой. Без циклов, морфинга, шрифтов и JavaScript. Один SVG весит около 3,4 КБ; фон прозрачный, есть светлая и тёмная версии. При `prefers-reduced-motion` сразу видна готовая подпись.

Генератор — `scripts/name.py` в репозитории [профиля](https://github.com/twoonemoon/twoonemoon). Нужен только Python 3: `python3 scripts/name.py`, проверка: `python3 scripts/check_name.py`. Полученные `assets/name-signature-{light,dark}.svg` копируются сюда без изменений.
